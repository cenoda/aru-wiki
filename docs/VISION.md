# 🌌 원신 3D 시간축 위키 — 상세 비전 및 기획서 (VISION)

## 1. 문제 의식: 왜 새로운 원신 위키가 필요한가?

『원신』은 수년에 걸친 업데이트로 방대한 세계관(티바트 역사, 마신전쟁, 켄리아, 강림자 등)과 수백 개의 임무가 얽혀 있는 거대 서사 게임입니다. 그러나 기존 위키(나무위키, Fandom 등)와 DB 사이트들은 다음과 같은 구조적 한계를 안고 있습니다.

1. **스포일러 무방비 노출**: 뉴비나 복귀 유저가 `v1.x`~`v2.x` 스토리를 밀다가 궁금한 용어나 인물을 검색하면, 문서 최상단부터 최신 버전(`v4.x`~`v5.x` 이후)의 치명적인 반전과 스포일러를 당합니다.
2. **스토리 진행 순서의 혼란**: 마신 임무, 전설 임무, 월드 임무, 그리고 지금은 플레이할 수 없는 '한정 이벤트 스토리'가 서로 어떤 선행 관계를 맺고 있는지 한눈에 파악하기 어렵습니다.
3. **가독성이 떨어지는 장문의 줄글**: 수만 자에 달하는 텍스트 벽(Wall of Text)으로 인해 사건의 인과관계나 인물 간 관계망을 직관적으로 이해하기 힘듭니다.
4. **공식 설정(Canon)과 유저 추측(Fan Theory)의 혼재**: 게임 내 텍스트로 확정된 사실과 유저들의 추측성 해석이 한 문단에 뒤섞여 서술되어, 무엇이 팩트이고 무엇이 가설인지 구분하기 어렵습니다.

본 프로젝트는 **순수 비영리(광고·후원 없음) 자체 서버 인프라**를 기반으로, 기존 위키의 방대한 정보를 합법적으로 흡수·재가공하여 **3D 공간과 버전별 시간축 위에 재구성하는 완전히 새로운 위키 플랫폼**을 구축합니다.

## 2. 6대 핵심 기능 상세 설계

### 기능 1. 스토리 임무 노드 그래프 (Quest Dependency Graph)
* **목적**: 유저가 스토리를 가장 몰입감 있고 자연스러운 순서로 감상할 수 있는 네비게이션 제공.
* **구성 내용**:
  * 마신 임무, 전설 임무, 초대 이벤트, 주요 월드 임무(예: 아란나라, 수선화 십자 등), 버전별 한정 이벤트 스토리를 노드로 배치.
  * **[필수 선행]**(게임 시스템상 잠금)과 **[권장 선행]**(스토리 이해 및 캐릭터 첫 대면 대사 변화 등 서사적 연결)을 서로 다른 선(Edge) 스타일로 시각화.
  * 지나간 한정 이벤트 노드의 경우, 핵심 요약 슬라이드 및 유튜브 스토리 다시보기 아카이브 링크를 함께 제공.
* **개인화 연동**: 유저가 자신이 클리어한 임무를 체크하면, 다음 추천 임무 경로를 하이라이트하고 미진행 구간의 스포일러를 자동 차단.

### 기능 2. 시각적 정보 전달 (Slide-Deck Visual Storytelling)
* **목적**: 줄글 읽기의 피로도를 줄이고 PPT 발표 자료나 인포그래픽 카드를 넘겨보듯 설정을 이해하게 함.
* **구현 전략 (지속 가능한 템플릿화)**:
  * 매 문서를 수작업으로 디자인하는 대신, **정형화된 JSON/Markdown 데이터를 입력하면 자동으로 PPT 슬라이드/카드 UI로 렌더링되는 표준 시각 컴포넌트**를 구축합니다.
  * **표준 슬라이드 타입 예시**:
    1. `[요약 카드]`: 3줄 핵심 정의 + 핵심 키워드 태그
    2. `[타임라인 비교 슬라이드]`: 사건 전(Before) vs 사건 후(After) 세계관 변화
    3. `[인물/세력 관계도 슬라이드]`: 중심 노드를 둘러싼 우호/적대/계약 관계 미니맵
    4. `[인게임 원문 근거 슬라이드]`: 서적, 성유물 스토리, 무기 돌파 소재 원문 발췌 및 하이라이트

### 기능 3. 인터랙티브 3D 위키 (Interactive 3D Knowledge Graph)
* **목적**: 지식 간 연결망을 입체적으로 탐험하는 압도적 몰입감과 시각적 경험 제공.
* **주요 인터랙션**:
  * 각 문서(인물, 신, 국가, 사건, 고대 문명, 용어)는 3D 우주 공간의 노드로 표현되며, 연관성이 높은 노드끼리 인력(Force-directed layout)으로 군집을 형성.
  * 특정 키워드 검색 시 카메라가 해당 노드로 워프하며, 연관 노드들이 중심 노드 주변으로 동적 재정렬됨.
* **UX 안전장치 (2D/3D 하이브리드 뷰)**:
  * 수천 개 노드가 한 번에 렌더링되어 거미줄처럼 엉키는 현상을 막기 위해, **선택된 노드의 1~2촌(Depth 1~2) 연결망만 선명하게 활성화(Local Sub-graph Filtering)**합니다.
  * 거시적 탐색은 3D로 즐기되, 실제 문서를 정독하거나 모바일에서 접속할 때는 즉시 **깔끔한 2D 마인드맵 + 슬라이드 리더 뷰**로 전환할 수 있는 원클릭 토글을 제공합니다.

### 기능 4. 기존 위키 데이터의 합법적·적극적 활용 (Legal Data Aggregation)
* **목적**: 초기 데이터 구축 기간을 획기적으로 단축하고 이미 검증된 방대한 고증 자료를 흡수.
* **실행 방안**:
  * 비영리(`NC`) 및 동일조건변경허락(`SA`), 출처 명시(`BY`) 원칙을 철저히 준수하여 나무위키, 영문 Fandom 위키 등의 텍스트를 수집.
  * 수집된 긴 줄글 데이터를 LLM 기반 구조화 파이프라인을 통해 **`[버전 태그] + [노드 간 관계(Edge)] + [슬라이드 카드 요약] + [원문 출처 메타데이터]`** 형태의 그래프 DB 데이터로 변환 및 정제.

### 기능 5. 주석 및 정보 신뢰도 구분 + 다중 해석 공존 시스템
* **목적**: 원신 고고학(Lore)의 핵심 재미인 '떡밥 추리'를 체계화하고 뇌피셜과 오피셜의 혼동을 방지.
* **3단계 신뢰도 배지 및 시각적 구분**:
  * 🟢 **Tier 1 [공식 확정 (Confirmed Canon)]**: 실선 연결 / 인게임 대사·도감에 직접 명시된 사실 (필수 주석: 해당 임무/서적명)
  * 🟡 **Tier 2 [유력 가설 (Strong Theory)]**: 굵은 점선 연결 / 직접 명시되진 않았으나 복수의 성유물·서적·상징이 교차 검증하는 정설급 해석
  * 🟣 **Tier 3 [추측 및 이설 (Speculation / Alternative)]**: 얇은 점선 연결 / 흥미로운 발상이나 소수 의견, 아직 근거가 부족한 추측
* **다중 학파(Multi-Branch Interpretation) 탭 & 유저 투표**:
  * 하나의 미스터리(예: *"천리의 주관자의 정체"*, *"페이몬의 기원"*)에 대해 단일 서술만 강요하지 않고, **[해석 A] / [해석 B] / [해석 C]** 슬라이드를 병렬 배치하고 유저들이 각 가설의 근거와 신빙성에 투표·토론할 수 있는 동적 백엔드 기능을 제공합니다.

### 기능 6. 원신 버전별 시간축 (Version Time-Machine)
* **목적**: 스포일러 완벽 방지 및 '역사적 시점'에서의 세계관 고고학 체험.
* **작동 방식**:
  * 화면 하단(또는 상단)에 **`v1.0` ➔ `v1.1` ➔ ... ➔ `v2.0` ➔ `v3.2` ➔ `v4.2` ➔ `최신 버전`으로 이어지는 마스터 타임라인 슬라이더**가 항상 존재합니다.
  * 예: 유저가 슬라이더를 `v2.1 (이나즈마 마신임무 직후)`로 맞추면:
    * `v2.2` 이후에 등장한 인물·지역 노드는 그래프에서 숨겨지거나 자물쇠 처리됩니다.
    * 이미 등장한 인물(예: 스카라무슈, 아를레키노 등)이라도 **`v2.1` 시점까지 공개된 행적과 당시 유저들의 추측만 슬라이드에 표시**되며, 수메르/폰타인 이후 밝혀진 진실은 노출되지 않습니다.
    * 버전을 한 단계씩 올릴 때마다 **"당시 추측(🟣)이었던 내용이 어떻게 공식 확정(🟢) 또는 폐기(❌)되었는지"** 그래프와 슬라이드가 변하는 과정을 애니메이션으로 감상할 수 있습니다.

## 3. 단계별 구축 로드맵 (Phased Roadmap)

1. **Phase 0 — 비전 수립 및 법적/데이터 아키텍처 정의 (현재 단계)**
   * 프로젝트 비전 문서화, AGPL-3.0 + CC BY-NC-SA 분리형 라이선스 정책 확립, 그래프 데이터 스키마 정의.
2. **Phase 1 — MVP: 버전별 스토리 임무 네비게이터 & 단일 핵심 테마 프로토타입**
   * 전체 마신/전설/핵심 월드/한정 이벤트 임무 선행 관계 그래프 구축.
   * 대표 고고학 테마 1개(예: `'켄리아와 심연 교단'` 또는 `'강림자와 천리'`)를 선정하여 3D 노드 + 버전 타임머신 + 슬라이드 뷰 프로토타입 구현.
3. **Phase 2 — 위키 데이터 구조화 파이프라인 가동**
   * 인게임 1차 사료(텍스트맵) 및 외부 CC 라이선스 위키 데이터를 버전별·슬라이드별로 분해·구조화하는 반자동 파서 및 검수 도구 구축.
4. **Phase 3 — 유저 참여형 다중 가설/주석 플랫폼 오픈**
   * 유저 계정별 스토리 진행도(스포일러 필터) 저장, 가설 등록 및 신뢰도 투표, 실시간 3D 노드 연결 제안 시스템 오픈.
