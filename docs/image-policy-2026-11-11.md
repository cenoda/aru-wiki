# 2026-11-11 인물 이미지 방침

**결정: B안 유지 — 정식 출시되어 게임 화면에서 확인할 수 있는 인물 이미지는 추출본이라는 이유만으로 배제하지 않는다.** B안은 약관 적합성이 확인된 방식이 아니라, Legal FAQ의 비상업 팬사이트 안내를 고려하면서 남는 불확실성을 받아들이는 운영 선택이다. HoYoverse가 추출 아이콘의 외부 위키 사용을 명시적으로 승인했다는 뜻이 아니다. 공식 근거와 미확인 범위는 [권리·운영 위험 검토](rights-risk-2026-11-11.md)에 구분한다.

유출 자료는 절대 사용·게시하지 않으며, HoYoverse의 이용약관(ToS)을 위반하는 행위를 하지 않는 것을 운영 원칙으로 한다. 이 준수 원칙은 모든 사용 방식의 적법성이나 약관 적합성을 이미 검증했다는 선언이 아니다. 위반이 확인된 자료·방식은 사용을 중단하고 수정·삭제한다.

## 1. 필요한 수

위키 수준이면 이름이 나오는 인물 전부에 이미지가 있어야 한다. 단계를 나눠 일부만 두는 방식은 쓰지 않는다.

| 구분 | 수 | 근거 |
|---|---|---|
| 임무 대사에 이름이 나오는 인물 | 약 3,490명 | `quest-characters.json` 이름 3,506개. Fandom 문서가 있는 인물 3,433명(별칭 27개를 합침) + 문서가 없는 인물 55명 |
| 그중 플레이 가능 캐릭터 | 약 124명 | Fandom 분류 `Playable Characters` 136개에서 여행자 원소별 문서 9개와 Manekin 문서 3개를 뺌. 출시 전 발표 캐릭터가 섞여 있을 수 있다 |
| 그중 임무 하나에만 나오는 인물 | 2,012명 | |

- 서적·설정에만 나오는 인물은 이 수에 들어 있지 않다. 넣으면 더 늘어난다.
- 플레이 가능 캐릭터를 뺀 약 3,370명은 대부분 공식 웹에 공개된 이미지가 없다.

## 2. 사용 범위

- 출시된 인물의 식별용 아이콘, 공식 공개 이미지, 인게임 스크린샷을 인물·임무 설명과 함께 사용한다. 아이콘이 없으면 실제 게임 화면에 근거한 초상을 확보한다.
- B안은 이미지에 대한 예외다. 직접 역공학·보호조치 우회·클라이언트 추출 작업을 허용하는 결정이 아니며, 텍스트맵 대량 덤프 및 기존의 글·사실 출처 제한은 유지한다.
- 베타·유출·미공개 자료는 받거나 게시하지 않는다. 사전 다운로드 파일에 포함되었다는 사실만으로 공개된 자료로 취급하지 않는다. 공개 여부를 확인하지 못한 이미지는 게시하지 않는다.
- Fandom은 이미지 취득 경로로 쓰지 않는다. Enka는 공식 API 문서에서 이미지 URL을 안내하지만 이는 HoYoverse의 외부 재배포·자체 호스팅 허락이 아니다. Enka 등 다른 경로는 해당 인물, 공개 버전, 원출처, 파일 출처, 제3자 권리 및 확인한 사용 조건을 파일별로 기록하고 검토한다. 별도 약관을 찾지 못했다는 사실로 약관이 없다고 단정하지 않는다.
- 게시 용도와 취득 과정은 각각 검토한다. 직접 촬영도 게임 이미지의 게시 권한을 자동으로 해결하지 않으며, 제3자 제공 파일도 출시 여부만으로 승인하지 않는다. 공개 여부나 제3자 사용 조건을 확인하지 못한 파일은 보류한다.
- 이미지에는 출처 및 권리 귀속을 표시하고, 프로젝트의 CC BY-SA 4.0 적용 대상에서 제외한다. 기본 권리 고지는 `© All rights reserved by COGNOSPHERE. Other properties belong to their respective owners.`로 한다.
- 이미지 크기·잘라내기·수량은 각 문서의 인물 식별과 설명에 필요한 범위로 정하고 그 용도를 기록한다. 독립적인 원본 에셋 모음이나 일괄 다운로드 서비스를 제공하지 않는다. 이는 자체 운영 제한이며, 영상 지침인 Legal FAQ Q3(4)를 비영리 위키의 포괄적 에셋 모음 금지로 확장한 결론이 아니다. 이 조치 자체가 법적 허용을 보장하는 것은 아니다.
- 이미지도 버전 선택기를 따른다. 나중에 밝혀지는 외형·정체는 해당 공개 버전부터 표시한다.
- AI 재작성은 인물 이미지 확보 방법으로 채택하지 않는다. 원본의 사용 근거 문제를 해결하지 못하고 외형 오류 및 검수 부담을 추가하기 때문이다.

## 3. 전 인물 이미지 확보

일부 플레이 가능 캐릭터만 초상으로 제공하는 방식은 채택하지 않는다. 전 인물을 대상으로 다음 목록을 만든다. 현재 확보 가능 수와 완료 일정은 조사 전이다.

| 항목 | 기록 내용 |
|---|---|
| 식별 | 인물 ID, 별칭, 인물임을 확인한 근거 |
| 외형 | 게임상 등장 여부, 아이콘·스크린샷 존재 여부 |
| 출처 | 원출처와 파일 URL, 취득 경로·확인일, 촬영자 등 제3자 권리, 사용 조건과 확인 근거 |
| 공개 | 실제 공개 버전 및 확인 근거, 스포일러 공개 버전 |
| 게시·가공 | 설명 대상 문서와 식별·설명상 필요성, 표시 크기·수량, 자르기·축소 등 변경 내용 |
| 검수 | 검수 상태·확인자·확인일, 미확보 또는 사용 보류 사유, 채택한 사용 근거와 남는 불확실성 |

현재 만날 수 없는 인물은 기존 촬영 자료와 기여를 검토하되 제3자 자료의 사용 조건도 확인한다. 외형 자체가 공개되지 않은 인물의 표현 방식은 별도 미결 사항이다. 임의로 외형을 생성하거나 일반 NPC의 수집을 이니셜로 대체하지 않는다.

## 4. 확인된 근거와 결정의 한계

원신 공식 [Legal FAQ Q2](https://www.hoyolab.com/article/143107)는 비상업 개인 팬사이트의 자료 사용을 다룬다. 스타레일 가이드를 원신의 허용 근거로 대체하지 않는다. 그러나 출시된 추출 아이콘의 외부 위키 게시·자체 호스팅을 명시적으로 허용한 문구는 확인하지 못했다.

B안은 이 불확실성을 공개한 운영 결정이다. 정식 출시·비영리·출처 표기만으로 약관 적합성이 확정되거나 삭제 요구가 배제된다고 주장하지 않는다. [위험 검토 문서](rights-risk-2026-11-11.md)에 사실, 판단, 미확인 범위와 대응을 기록한다.

이미지 사용 결정은 Fandom 텍스트 취득이나 외부 LLM 처리의 허용 결정과 분리한다. 덤프 제공이나 LLM 재작성은 게임 원문·이미지의 권리 문제를 해결하지 않는다. 공개 전에는 파일별 목록과 검수, 이용자가 확인할 수 있는 출처·권리 표시, 대상 파일 및 참조의 삭제·교체 수단을 구현·확인한다. 이 문서는 해당 구현이 완료되었다는 선언이 아니다.

## 5. 권리 문의와 대응

모든 권리 관련 질문과 수정·삭제 요청은 [contact@aru.wiki](mailto:contact@aru.wiki)로 받으며, **수신 후 72시간 이내에 답변한다.** 이는 답변 기한이며, 모든 사안의 최종 해결이 72시간 안에 끝난다는 뜻은 아니다. HoYoverse의 수정·삭제 요청은 즉시 따른다. 그 밖의 권리자 요청도 확인하고 필요한 수정·삭제를 신속히 진행한다.

## 6. 변경 이력

- 처음에는 A안(이미지 추출본도 금지)과 B안을 검토했다.
- 2026-11-10 검토 기록과 `design.md`에 먼저 쓰였던 ‘B+C 결합 결정’ 및 ‘원칙 명확화’는 당시 승인되지 않은 내용이었다.
- 이번 사용자 지시에 따라 B안을 문서화한다. 단순한 문구 명확화가 아니라 이미지에 대한 정책 예외이며, 명시적 사용 허락을 확인했다는 의미가 아니다.
- 2026-11-11 수정: B안 유지와 남는 불확실성 수용을 명시하고, 파일별 취득·게시 검토, Enka 안내의 범위, 자체 에셋 모음 제한 및 텍스트·LLM 결정과의 분리를 반영했다.
