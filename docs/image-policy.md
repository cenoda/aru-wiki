# 인물 이미지 방침

**B안: 정식 출시되어 게임 화면에서 확인할 수 있는 인물 이미지는 추출본이라는 이유만으로 배제하지 않는다.** 권리 근거, 남는 불확실성, 문의 대응은 [권리·운영 위험 검토](rights-risk.md)에만 적는다. 이 문서는 이미지를 어떻게 쓰는지만 정한다.

## 1. 범위: 쓸 수 있는 만큼 쓴다

이미지를 확보할 수 있는 인물부터 붙인다. 모든 인물의 이미지가 모일 때까지 기다리지 않는다. 이미지가 없는 인물은 이미지 없이 보여 준다.

| 구분 | 수 (2026-11 데이터) | 확보 경로 |
|---|---|---|
| 임무 대사에 이름이 나오는 인물 | 약 3,490명 | |
| 그중 플레이 가능 캐릭터 | 약 124명 | Enka 공식 API 문서가 안내하는 아이콘 URL, 공식 공개 이미지 |
| 나머지 인물 | 약 3,370명 | 정해진 경로 없음. 직접 찍은 인게임 스크린샷, 기여 |

## 2. 규칙

- 출시된 인물의 식별용 아이콘, 공식 공개 이미지, 인게임 스크린샷을 인물·임무 설명과 함께 쓴다.
- 베타·유출·미공개 자료는 받지도 게시하지도 않는다(Legal FAQ Q9). 사전 다운로드 파일에 들어 있다고 공개된 것으로 보지 않는다. 공개 여부를 모르면 게시하지 않는다.
- 직접 역공학, 보호조치 우회, 클라이언트 추출은 하지 않는다(이용약관 3(b)(viii)). 글·사실의 데이터마이닝 금지(design.md 1절)는 그대로다.
- Fandom에서는 이미지를 받지 않는다(Fandom 이용약관은 텍스트 외 콘텐츠의 재사용을 허락하지 않는다).
- Enka 등 외부 경로는 필요한 파일만 소량·저속으로 받는다.
- 이미지마다 권리 고지 `© All rights reserved by COGNOSPHERE. Other properties belong to their respective owners.`를 표시하고, 프로젝트의 CC BY-SA 대상에서 뺀다.
- 인물 식별에 필요한 크기로 쓰고, 원본 모음이나 일괄 다운로드는 제공하지 않는다.
- 이미지도 버전 선택기를 따른다. 나중에 밝혀지는 외형·정체는 그 버전부터 보인다.
- AI로 다시 그린 이미지는 쓰지 않는다. 권리 문제가 풀리지 않고 외형이 틀릴 수 있다.
- 외형이 공개되지 않은 인물은 임의로 그리지 않는다.

## 3. 파일 기록

삭제 요청이 오면 해당 파일과 그 파일을 쓰는 곳을 바로 찾아 지울 수 있게, 파일마다 다음만 기록한다. 가능한 것은 스크립트로 채운다.

| 항목 | 내용 |
|---|---|
| 인물 | 인물 ID |
| 출처 | 파일 URL 또는 "직접 촬영", 받은 날짜 |
| 공개 버전 | 그 외형이 처음 공개된 버전 |
| 가공 | 자르기·축소 여부 |

## 4. 지금 쓰는 이미지 (2026-11-11)

- 임무 카드: 중심 인물이 플레이 가능 캐릭터인 막 96개 중 아이콘이 붙은 캐릭터 79명(`data/generated/image-files.json`). Enka API 문서가 안내하는 `https://enka.network/ui/UI_AvatarIcon_Side_*.png`를 2초 간격으로 한 번씩 받았고 가공하지 않았다(128×128, 화면에서 축소).
- 중심 인물은 `scripts/images/card-figures.mjs`가 정한다. 전설·월드 임무는 정보 상자 `character`, 마신 임무의 Interlude Chapter와 정보 상자 `character`가 Traveler인 막은 모든 하위 임무에 나오는 플레이 가능 캐릭터가 한 명뿐일 때만. 사람이 고르면 `data/manual/card-figures.json`.
- 아이콘 이름은 내부 이름이라 이름으로만 짝짓는다(추출 텍스트인 Enka `loc.json`은 쓰지 않는다). 짝을 찾지 못한 진(Jean)·한운(Xianyun)은 아이콘 없이 둔다. 철자가 비슷해서 짝지은 9명(`match`가 `near`·`prefix`: 엠버·노엘·토마·리넷·리니·백출·알하이탐·라이덴 쇼군·스커크)도 사람이 확인하지 않았다. 확인하면 `data/manual/enka-icons.json`에 적는다.
- 공개 버전은 Fandom 덤프 캐릭터 정보 상자의 `releaseDate`에서 계산하고, 버전 선택기가 그보다 앞이면 아이콘 대신 지역 문장을 보인다. 데이터 범위(7.1) 밖이면 받지 않는다.
- 이미지가 없는 카드는 자체 제작 지역 문장(`src/emblems.tsx`, 미리보기 `?view=emblems`). 지역마다 떠올리기 쉬운 건물·지형의 실루엣이다(2026-11-11 사용자 확인).

## 5. 변경 이력

- 2026-11-11: A안(추출 이미지 금지) 대신 B안으로 결정.
- 2026-11-11: "모든 인물을 확보하기 전에는 일부만 쓰지 않는다"는 문장을 지우고 확보할 수 있는 만큼 쓰기로 바꿨다(사용자 결정). 파일 기록은 삭제 대응에 필요한 항목만 남겼다. 중복된 권리 설명은 위험 검토 문서로 모았다.
